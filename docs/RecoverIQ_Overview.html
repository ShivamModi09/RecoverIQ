Treaty Contract in which a reinsurer agrees to pay part of the insurer's large losses.
Retention The amount of each loss the insurer pays itself before the reinsurer pays.
Limit The maximum dollar amount the reinsurer will pay for one loss event.
Recovery The money the primary insurer claims back from the reinsurer.

The Core Problem: How Reinsurance Money Gets Missed

One windstorm damages four insured warehouses. Each claim is below the $2.0M retention threshold, so none is individually sent for review. But the treaty aggregates the entire storm as one single event — together the claims breach retention!

💡 Why It Is Worth Solving

  • Straight to bottom-line: Recovered money is pure profit. Unbilled recoveries are lost forever.
  • Highly manual today: Analysts manually reconcile complex multi-page treaties in spreadsheets.
  • Common leaks: Event aggregations missed, claims expanding after billing, un-reconciled broker payments.
  • Low client friction: Historical batch analysis — does not touch fragile live core systems.

🎯 MVP Scope Boundaries

  • Included: Commercial property claims (1-year batch), Excess of Loss (XOL) treaties, automated page-cited clause extraction, deterministic recovery calculator, 3-way variance reconciliation screen.
  • Excluded: Real-time new claims intake, core system direct billing APIs, contested legal litigation.

🎯 Senior Reviewer Guidance (Sayan Ghosh & Biswajit Das)

1. Strategic Nuance

Frame the tool as solving Leakage from Complex Treaty Interpretation rather than just "someone forgot to read the paper". Emphasize layers, limits, and multi-broker statements.

2. Add Realistic Ingestion Files

Include Broker Bordereaux (BDX) and Historical Loss Runs / Case Reserves. This makes the synthetic dataset indistinguishable from enterprise reinsurance operations.

3. Breadth over Depth (Pareto 80/20)

Show the complete end-to-end flow cleanly. Don't get stuck on edge cases; demonstrate high confidence, transparent citations, and intuitive visuals.

4. UI / Pipeline Visualization

Leverage Shivam's frontend experience to display clear step-by-step progress, evidence side-by-side, and confidence metrics on every dollar calculation.
